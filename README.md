# XsyndaOS
XsyndaOS - операционная система консольного типа, созданная для максимально простого пользования компьютерами, работой с файлами и другими приложениями, которые вы можете скачать в Store.

## Гайд на установку
1. Введите в консоль `wget run https://raw.githubusercontent.com/Entaru-Studio/XsyndaOS/refs/heads/main/install.lua`
2. Дождитесь окончания установки. Если установка не началась, введите install.lua
3. Готово. Вы теперь можете использовать систему
